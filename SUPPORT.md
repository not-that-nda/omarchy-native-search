# Support and feedback

Native Search is an optional community tool. It is not bundled with or maintained by the Omarchy project.

| Need | Place |
| --- | --- |
| Installation or usage help | [Q&A](https://github.com/not-that-nda/omarchy-native-search/discussions/categories/q-a) |
| Feature idea or vote | [Ideas](https://github.com/not-that-nda/omarchy-native-search/discussions/categories/ideas) |
| Reproducible bug | [Bug report](https://github.com/not-that-nda/omarchy-native-search/issues/new/choose) |
| Release updates | [Releases](https://github.com/not-that-nda/omarchy-native-search/releases) and [Announcements](https://github.com/not-that-nda/omarchy-native-search/discussions/categories/announcements) |

## Low-noise participation

Search existing issues/discussions first. Upvote an existing idea instead of adding “+1” comments. One problem per report makes it easier to reproduce and track. Include the Native Search version, Omarchy/Quickshell versions, reproduction steps, and what you expected. Use synthetic filenames in examples and remove personal paths, emails and tokens from screenshots/logs.

## Expectations

This is maintained on a best-effort basis and feedback is reviewed in batches. There is no response-time or feature-delivery guarantee. Votes help prioritize useful work but do not promise implementation. A `status:accepted` label means the outcome is worth pursuing; a target release is stated only when actually scheduled.

Labels distinguish new reports (`needs-triage`), accepted work, in-progress work and blocked items. Questions can be marked answered in Q&A; completed bugs/changes link to their fix or release. Reports are not automatically closed just because they are old.

Before treating a missing file as a bug, check the selected roots/filters, index age, omissions and whether the drive is mounted. Current versions need the Quickshell plugin shell; older Walker-only desktops are outside the supported interface.

Do not send Native Search-specific requests to Omarchy's bug tracker. Genuine upstream problems should be isolated and reproduced separately.
