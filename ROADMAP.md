# Roadmap

This page records direction, not delivery promises. [Vote or propose an idea](https://github.com/not-that-nda/omarchy-native-search/discussions/categories/ideas).

## Available in the preview

- Native popup with fixed centered input and downward results expansion.
- Per-root indexed filename/path search, literal/fuzzy modes and filters.
- Right-side previews and open/reveal/copy actions.
- Bottom settings form, configurable scope and reversible standalone installation.

## Validation priorities

- Independent clean-machine graphical install/upgrade/remove reports on supported Omarchy shell versions.
- Keyboard, fractional-scale and multi-monitor feedback beyond the original test environment.
- Clearer diagnostics for unsupported shell/API versions.

## Candidates, not scheduled commitments

- Arch/AUR packaging to simplify installation and upgrades.
- Optional Recoll document-content search in a distinct mode.
- Better preview navigation and handling of narrow displays.
- Improvements prioritized from reproducible bugs and upvoted Ideas.

## Project boundary

Native Search remains optional standalone software. Inclusion in Omarchy's default installation is not a goal. Avoid expanding it into a general assistant or cloud service; local search and a responsive desktop interface are the focus.
